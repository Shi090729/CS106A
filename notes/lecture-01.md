# Lecture 01 - Introduction to Programming Methodology

## Course Content

### Programming Methodology

CS106A teaches more than Java syntax. Knowing a programming language does not automatically make someone a good programmer. The course focuses on designing programs that are correct, clear, well structured, and maintainable.

Programming should therefore be treated as a problem-solving and software-design discipline, not simply as writing instructions that happen to run.

### Collaboration and Debugging

Discussing concepts and solution strategies is acceptable, but each implementation must be written independently. External help, starter code, and third-party materials should be acknowledged.

A **bug** is an error in a program. **Debugging** is the process of finding, understanding, and correcting errors. Bugs are expected, and debugging is a normal part of programming.

### Introduction to Karel

Karel is a small robot-programming environment used before full Java programming. Its limited world allows beginners to focus on algorithms, decomposition, control flow, correctness, and readability without being distracted by a large language.

Karel lives on a rectangular grid:

- Horizontal lines are streets.
- Vertical lines are avenues.
- Intersections are corners.
- Walls can block movement.
- Beepers are markers that Karel can pick up or place.
- Karel carries beepers in a beeper bag.

## My Takeaways

The opening lecture changed the way I think about an introductory programming course. The goal is not simply to collect Java syntax, but to learn how to turn a vague problem into a clear procedure that another person can understand and maintain.

Karel also feels like a sensible starting point rather than a toy. By removing most of the language, it leaves nowhere to hide weak decomposition or unclear reasoning. I also want to remember that debugging is expected work. A bug is evidence that my mental model and the program's behavior differ; finding that difference is part of programming, not proof that I should already have known the answer.
