# Section 02 - Simple Java

This section contains the two exercises from the official handout:

- `Fibonacci` prints every Fibonacci term below 10,000.
- `RobotFace` draws a centered face using a rectangle, two circles, and a mouth.

The exercises practice `while` loops, named constants, variable updates, graphics coordinates, and decomposition into small methods. Both programs compile with the course ACM library. The face was also checked at different window sizes to confirm that it remains centered, and a rendered result is saved in `screenshots/`.
