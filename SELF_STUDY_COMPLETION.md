# CS106A Self-Study Completion Statement

## Programming Methodology

I completed a self-directed study of Stanford CS106A: Programming Methodology using the publicly available course materials. My goal was not only to follow the lectures, but to understand the ideas well enough to explain them, implement them, debug them, and apply them in complete programs.

## Work Completed

- Studied all 28 lectures and wrote a complete set of lecture notes.
- Completed the exercises for Sections 1–9, including the conceptual and tracing questions.
- Implemented and verified all seven programming assignments:
  1. Karel the Robot
  2. Simple Java Programs
  3. Breakout
  4. Hangman
  5. Yahtzee
  6. NameSurfer
  7. FacePamphlet
- Completed written solutions for the practice midterm and final examination.
- Built and ran the programming projects and preserved source code, required data, and selected runtime screenshots as evidence of completion.

## Knowledge and Skills Developed

Through this work, I developed practical experience with:

- algorithmic thinking, decomposition, method contracts, and debugging;
- Java syntax, control flow, methods, classes, inheritance, interfaces, and object references;
- strings, arrays, `ArrayList`, maps, iterators, files, and exceptions;
- graphics, animation, event-driven programming, interactors, and GUI layout;
- searching, sorting, basic efficiency analysis, data modeling, and representation invariants;
- designing larger programs whose classes have clear and maintainable responsibilities.

The progression from Karel to FacePamphlet strengthened my ability to turn an informal specification into a working program. It also taught me to treat testing and revision as part of development rather than as separate steps performed only after the code is written.

The lecture notes, section work, assignments, exam answers, and supporting project files in this repository form the record of my completion. This statement documents independent self-study and does not represent a Stanford-issued credential.
